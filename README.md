# Exploration statistique de la violence domestique envers les femmes

## Description du projet
Ce projet propose une analyse exploratoire des données sur la violence domestique envers les femmes à partir d’un dataset socio‑démographique. L’objectif est de comprendre comment des facteurs tels que l’âge, l’éducation, le statut marital, l’emploi et le revenu influencent la probabilité d’être victime de violence domestique. L’analyse permet d’identifier des profils à risque et de fournir des insights utiles pour la prise de décision, la sensibilisation et l’élaboration de politiques publiques.

## Objectifs
-Explorer la distribution des victimes et non‑victimes dans le dataset. 

-Étudier les relations entre variables socio‑économiques et la violence domestique. 

-Fournir des visualisations descriptives qui illustrent les patterns observés.
